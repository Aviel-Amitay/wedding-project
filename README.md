# Wedding Invitation & RSVP Site

A Hebrew-language wedding invitation and RSVP site backed by Firebase Firestore.  
Guests submit RSVPs without logging in. An admin page (Google login) shows all responses.

---

## Deploy from scratch

### 1. Create a Firebase project

1. Go to [console.firebase.google.com](https://console.firebase.google.com) → **Add project**
2. **Databases & Storage** → **Firestore** → Create database → start in **production mode**
3. **Security** → **Authentication** → Get started → **Sign-in method** → enable **Google**

### 2. Get your Firebase config

Firebase Console → Click on your project → Settings → Your apps → **Add app** (Web) → register it →  
copy the config object, by changeing to config, under the SDK setup and configuration:

```js
const firebaseConfig = {
  apiKey:            "...",
  authDomain:        "...",
  projectId:         "...",
  storageBucket:     "...",
  messagingSenderId: "...",
  appId:             "..."
};
```

### 3. Get your VAPID key (push notifications)

Firebase Console → Project Settings → **Cloud Messaging** → Web configuration →  
**Web Push certificates** → **Generate key pair** → copy the key.

### 4. Set Firestore Security Rules

Firebase Console → Firestore Database → **Rules** → replace with:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Guests (no login) can check duplicates and submit RSVPs
    match /rsvps/{doc} {
      allow read, write: if true;
    }

    // Guests can submit blessings; only logged-in admin can read them
    match /blessings/{doc} {
      allow write: if true;
      allow read: if request.auth != null;
    }

    match /admins/{doc} {
      allow read: if request.auth != null;
      allow write: if request.auth != null
        && request.auth.token.email == "your-email@gmail.com";
    }

  }
}

```

Click **Publish**.

### 5. Create your local `.env`

```bash
cp .env.example .env
```

Fill in `.env` with the values from steps 2–3:

```
FIREBASE_API_KEY=AIza...
FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
FIREBASE_PROJECT_ID=your-project
FIREBASE_STORAGE_BUCKET=your-project.firebasestorage.app
FIREBASE_MESSAGING_SENDER_ID=123456789
FIREBASE_APP_ID=1:123456789:web:abc123
ADMIN_EMAIL=your-email@gmail.com
VAPID_KEY=your-vapid-key
```

`ADMIN_EMAIL` is the Google account that can log into `admin.html`.

- You can later add an additional admin thrughu the admin panel.

### 6. Generate `config.js` for local dev

```bash
bash build.sh
```

This writes `config.js` (gitignored). Run this again any time you change `.env`.

### 7. Run locally

Firebase Google Auth requires a real HTTP origin — open via a local server, not `file://`.

```bash
# Node (install from nodejs.org if needed)
npx serve .

# Python
python -m http.server 8080
```

Then open `http://localhost:8080` (RSVP form) and `http://localhost:8080/admin.html` (admin).

### 8. Deploy to Netlify

1. Push the repo to GitHub
2. [app.netlify.com](https://app.netlify.com) → **Add new site** → import from GitHub
3. Build settings are already in `netlify.toml` — no changes needed
4. **Site configuration** → **Environment variables** → add all 8 variables from your `.env`
5. **Deploys** → **Trigger deploy** → **Deploy site**

Netlify runs `bash build.sh` automatically, injecting the env vars to produce `config.js`.

### 9. Add `localhost` to Firebase authorized domains (first time only)

Firebase Console → Authentication → Settings → **Authorized domains** → confirm `localhost` is listed.  
If not, click **Add domain** and add it.

## Project structure

```
├── index.html          # Invitation + RSVP form (public)
├── admin.html          # Admin dashboard (Google login required)
├── css/style.css       # Styles
├── images/             # Invitation photo
├── config.js           # Generated by build.sh — gitignored, never commit
├── .env                # Your secrets — gitignored, never commit
├── .env.example        # Template — safe to commit
├── build.sh            # Generates config.js from env vars
└── netlify.toml        # Netlify build config
```

## Firestore collections

| Collection   | Written by       | Read by         |
|-------------|-----------------|----------------|
| `rsvps`      | Guest (public)   | Admin (auth)    |
| `blessings`  | Guest (public)   | Admin (auth)    |
| `admins`     | Admin (auth)     | Admin (auth)    |
| `fcm_tokens` | Admin (auth)     | Admin (auth)    |
